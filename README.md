# Proyecto de Programación y Ciberseguridad

Este repositorio reúne una colección de proyectos desarrollados durante laboratorios de la universidad en un entorno controlado y con fines exclusivamente educativos. Incluye prácticas de programación en Python, una demostración de SQL Injection mediante código SQL, y simulaciones de técnicas y ataques de ciberseguridad como Keylogger, Ransomware, Ataque de Diccionario, Bot, Sniffer, Escaneo de Puertos y ARP Spoofing. El objetivo de estos proyectos es comprender su funcionamiento, identificar sus riesgos y fortalecer los conocimientos en desarrollo seguro, redes y ciberseguridad.

> Aviso:Todo el contenido de este repositorio fue creado únicamente con fines académicos y de investigación. Las pruebas fueron realizadas en entornos de laboratorio autorizados y no deben utilizarse contra sistemas o redes sin el permiso correspondiente.
